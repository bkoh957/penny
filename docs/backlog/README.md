# Backlog

Ideas the engine has earned but has not yet planned. One file per item,
`YYYY-MM-DD-slug.md`, dated the day the idea was recorded rather than the day it
might be built.

## What belongs here

A backlog note is written **when a real book hits a real limit** — a check that
blocks work it should not block, a rule that costs more to obey than the failure
it prevents, a workaround that shows up twice. The note records the evidence
while it is fresh, so the eventual spec argues from a case rather than a hunch.

## What does not

- **A defect.** If the engine is wrong, fix it.
- **A series' problem.** If the fix belongs in a genre pack or one series' data,
  it is not an engine feature. (CLAUDE.md, the one architectural rule.)
- **Something already planned.** `docs/superpowers/specs/` holds designs and
  `docs/superpowers/plans/` holds the task lists that implement them. A backlog
  note graduates *into* a spec and is then marked graduated, not deleted.

## Shape of a note

Problem · Evidence from a real book · What it costs today · Sketches, with the
objection to each · Why not now. The sketches exist to be argued with; a note
that proposes one option and likes it has not done its job.
